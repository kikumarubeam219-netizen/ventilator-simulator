# 人工呼吸器グラフィック・3D解剖動態シミュレーター

人工呼吸器のグラフィックモニター（$P_{aw}$ / $Flow$ / $Volume$）と、生体内部の動態（3Dホログラフィック肺・気管支ツリー・横隔膜・心拍動）を完全同期させて可視化する教育用Webシミュレーターです。

呼吸の運動方程式に基づくリアルタイム物理演算（60fps）を行い、パラメータ変更に伴う波形変化や非同調（Auto-PEEP、ミストリガー等）を再現します。

---

## 主な機能

### 1. グラフィック波形モニター（Canvas 2D）
* **気道内圧（$P_{aw}$）**: 実測値 $P_{peak}$、$P_{plat}$、肺胞内圧 $P_{alv}$（点線）、設定PEEP（破線）
* **流速（$Flow$）**: 吸気（正）、呼気（負）のリアルタイム波形描画
* **換気量（$Volume$）**: 呼気換気量 $V_{te}$ の積算表示
* **リアルタイム数値バッジ**: 波形の右端に追従する現在値タグ表示

### 2. 3D胸部解剖・横隔膜動態モデル（Three.js / WebGL）
* **ホログラフィック・フレネル透過肺**:
  * 単一の数学的曲面による滑らかな解剖学的肺形状（右3葉・左2葉・心切痕）
  * 葉間裂（斜裂・水平裂）の繊細なミニマル発光ライン
* **肺胞内圧（$P_{alv}$）連動微細点群（約2,800点のPoints）**:
  * 肺内部に分布する発光ドット群が呼吸に合わせて放射状に拡張
  * 肺胞内圧の上昇に応じて、シアン/ローズ（低圧時）からアンバー/オレンジ（高圧時）へと色温度が動的にシフト
* **解剖学的X線肋骨・骨格**:
  * 背側から腹側へ向かって尾側に約25〜30度傾斜する極細の半透明肋骨アーチ
* **流線型気道ツリー**:
  * 滑らかな気管および第1〜第4分岐気管支ネットワーク
* **3D横隔膜ドーム**:
  * 患者の自発吸気努力（$P_{mus}$）および換気量に同期して尾側（下方）へ平坦化・下降
* **リアルタイム360度操作**:
  * マウスドラッグによる自由回転・ズームイン/アウト
  * 視点プリセット切り替え（正面 / 斜め立体 / 側面 / 横隔膜ドーム）
  * 心臓表示のON/OFF切り替え

### 3. 人工呼吸器モード＆パラメータ設定
* **換気モード**: A/C（アシストコントロール）、SIMV、PSV（プレッシャーサポート）
* **制御方式**: PCV（従圧式）、VCV（従量式：矩形波 / 漸減波、吸気ポーズ）
* **患者側パラメータ**: 自発呼吸数、吸気努力（$P_{mus}$）、肺コンプライアンス（$C$）、気道抵抗（$R$）
* **プリセットシナリオ**:
  1. 正常換気（A/C-PCV）
  2. プラトー圧測定（VCV + Pause）
  3. Auto-PEEP ＆ ミストリガー（トリガー不全）

## 構成ファイル

```text
ventilator-sim/
├── index.html                  # メインHTML・UIレイアウト（Tailwind CSS）
├── README.md                   # プロジェクト説明書
├── .gitignore                  # Git除外設定
└── src/
    ├── main.js                 # アプリ統合・メインループ
    ├── models/
    │   ├── Types.js            # パラメータ定数・初期設定
    │   └── VentilatorEngine.js # 呼吸の運動方程式・各モード物理エンジン
    └── views/
        ├── AnatomyRenderer.js  # 3D WebGL解剖・横隔膜レンダラー（Three.js）
        └── WaveformMonitor.js  # Canvas波形モニター描画クラス
```

## ローカルでの実行方法

ビルドツール不要で、ブラウザネイティブ（ES Modules）でそのまま動作します。

```bash
# ローカルサーバーの起動例
npx serve .
# または
python -m http.server 3000
```

ブラウザで `http://localhost:3000` を開いてご利用ください。
